# Portability checklist (use when code cannot be run)

Answer yes or no to each. Any "no" needs a fix.

1. Does the folder name match the `name:` line exactly?
2. Is `name:` lowercase letters, numbers, and hyphens only?
3. Is the description 600 characters or fewer, third person, with "Use when"?
4. Does the description contain the user's real trigger phrases?
5. Is the body under 150 lines?
6. Are the steps numbered, one action each, starting with a verb?
7. Does the body avoid product-specific tool names?
8. Does every step needing a capability say what to do if it is missing?
9. Is there one short, correct example of the output?
10. Are all `references/` and `scripts/` files named in SKILL.md actually present?
11. Is private data kept out of SKILL.md?
12. If it touches private data, is it in AI-Skills-Local, not AI-Skills-Claude?
