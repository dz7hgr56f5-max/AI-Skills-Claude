# Style guide for meeting summaries

Read this only when unsure how to word something.

- Use plain words and short sentences.
- Write decisions in the past tense: "Launch moves to November 14."
- Write action items starting with a verb: "Send the new deck."
- Use first names as they appear in the notes. Do not add last names.
- Write dates the way the notes wrote them, then add the full date only if the
  notes give enough to be sure. "Friday" stays "Friday" if no date is given.
- Do not soften or sharpen what was said. "Maybe we should" is an open question,
  not a decision.
