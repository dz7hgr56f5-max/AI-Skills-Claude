# Daily Capture

## Purpose

Turn something you came across — a quote, article, recipe, or your own idea — into a
short, dated entry with a category, so it's easy to find again later instead of
getting buried in one long notes file.

## Instructions

1. Read what the user pasted or described.
2. Pick exactly one category from this list, based on the content: Quote, News,
   Recipe, Health, Financial, Idea. If more than one could fit, pick the closest one
   and do not invent a new category.
3. If the content is a quote or other exact wording (like a recipe's ingredient
   list), copy it word for word. Do not paraphrase or shorten it.
4. If the user gives a source (a publication, author, person, or link), include it
   on a Source line exactly as given. If no source is given, leave that line out
   entirely rather than guessing one.
5. If the user adds their own reaction or thought, include it on a Note line in
   their own words. If they didn't add one, leave that line out.
6. Use today's date for the entry.
7. Write the entry using the layout below, then stop. Do not add commentary,
   alternatives, or ask if they want anything else.

 ## Entry layout

Use this layout for the entry: 
### <Category> — <date>

<the content, word for word if it's a quote or similar>
Source: <only if given>
Note: <only if given>


Example, using what the user described about a Proust quote found via an Apple News
article:
### Quote — 2026-10-06

"The only true voyage of discovery, the only fountain of Eternal Youth, would be not
to visit strange lands but to possess other eyes, to behold the universe through the
eyes of another, of a hundred others, to behold the hundred universes that each of
them beholds, that each of them is."
Source: BBC, via Apple News
Note: Liked the quote and want to look into reading more Proust. 


## Rules

- Never invent a category that isn't on the list.
- Never add words to a quote, or change its wording, spelling, or punctuation.
- Never guess a source. If none is given, leave the Source line out entirely.
- Never add a Note the user didn't give you. An empty Note line is worse than no line.
- If nothing clearly fits any category, use Idea rather than leaving it uncategorized.


## Example

Input: "saw a recipe for brown butter chocolate chip cookies on seriouseats.com,
want to try it this weekend"

Good output:

### Recipe — 2026-10-06
Brown butter chocolate chip cookies
Source: Serious Eats
Note: Want to try this weekend.

## Notes

- If an entry ever includes your own financial or health specifics (not something
  you read elsewhere, but your own numbers or condition), keep that entry in a
  private note rather than anywhere shared or synced.
- This skill only formats text. It cannot save anything on its own, so the entry
  still needs to be pasted into wherever you keep your notes.
